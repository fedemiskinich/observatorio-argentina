# Observatorio Argentina 0.14-public

Public baseline prepared for the first GitHub release.

## Repository preparation
- Project identity and package metadata updated to Observatorio Argentina.
- MIT license preserved for upstream code and extended with a notice for Observatorio Argentina modifications.
- Third-party notices separated from the source-code license.
- README rewritten around the Argentina situational-awareness / OSINT / GEOINT project.

- Contributor setup points to the Observatorio Argentina repository.
- Local caches and generated/private working directories removed from the release package.
