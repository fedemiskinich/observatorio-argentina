# Roadmap — Observatorio Argentina

This roadmap describes research and engineering directions, not guaranteed release dates.

## 0.14 — Public baseline
- Repository hygiene, licensing and third-party notices.
- Argentina-focused documentation and onboarding.
- Public-source provenance and integrity criteria.
- Local custom elements and GeoJSON workflows.

## Next
- Expand verified Argentine public-data connectors.
- Improve environmental-event and flood context layers.
- Improve 2D/3D navigation and territorial exploration.
- Normalize source health, freshness and provenance indicators.
- Add timeline/event correlation views.
- Continue experimental AI-assisted analysis with human review.

## Research direction
- Multi-source event correlation.
- Territorial situational awareness.
- Explainable contextual hypotheses from public signals.
- Reproducible OSINT/GEOINT workflows.

New roadmap items should preserve the project's privacy, provenance and responsible-use principles.
